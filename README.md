# Healthcare Data Analytics Project

## Project Title
Care Transition Efficiency & Placement Outcome Analytics

## Objective
This project analyzes the HHS Unaccompanied Alien Children dataset to understand trends in children apprehended, transferred, admitted to HHS care, and discharged.

## Tools Used
- Microsoft Excel
- Google Sheets
- GitHub

## Dataset
HHS Unaccompanied Alien Children Program Dataset

## Analysis Performed
- Data Cleaning
- Descriptive Statistics
- Trend Analysis
- Data Visualization

## Key Insights
- Daily trends of children apprehended were analyzed.
- HHS care population was monitored over time.
- Transfers and discharges were compared.
- Charts were created to identify patterns.
